# 第三方工具集成：批量生成字幕 / 马赛克破解

这两个功能的特点一样：**本程序只是一层界面，真正干活的是别人写的程序**。
所以它们**不包含**、也不会替你下载那些程序 —— 你需要自己准备。

这份文档就是把你需要准备什么、去哪儿拿、怎么配、怎么用，一次说清楚。

---

## 一、总览

| 功能页面 | 依赖的第三方程序 | 它负责什么 | 本程序负责什么 |
| --- | --- | --- | --- |
| ✍️ 批量生成字幕 | `infer.exe`（Faster-Whisper / TransWithAI 打包版） | 语音识别、翻译、生成字幕文件 | 批量排队、断点续跑、进度与日志、生成后去重/拆长句、从库里挑出缺字幕的视频 |
| 🔓 马赛克破解 | `lada-cli.exe`（Lada） | 马赛克检测与修复（真正的重活） | 批量排队、并发控制、显存门控、进度解析、**产出时长校验**、与「破解视频替换」串成流水线 |

两者都**不需要**把程序放到本程序的目录里 —— 你解压到任意位置，
在本程序里告诉它路径即可。**路径留空会自动查找**常见位置。

## 二、批量生成字幕

### 2.1 去哪儿下载

- 上游项目：**https://github.com/TransWithAI/Faster-Whisper-TransWithAI-ChickenRice**
- 开发团队：AI汉化组

到该仓库的 Releases 下载 Windows 打包版，解压后目录里应该至少有：

```
infer.exe            ← 就是这个（本程序需要指向它）
models/              ← 模型权重（打包里自带，不需要另外下载）
generation_config.json5   ← 生成参数（可选，高级用法）
```

> 该仓库只有部分版本提供打包好的 Release。如果你的机器上没有现成的包，
> 也可以按上游 README 自己跑 `pip install -r requirements.txt` 那套流程 ——
> 但那样得到的是 Python 环境而不是 `infer.exe`，本程序只对接 `infer.exe` 这种打包形态。

### 2.2 前置条件

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10/11 64 位（该打包版是 Windows 二进制） |
| GPU 模式 | NVIDIA 显卡 + 较新的驱动。显存不足可以改用 CPU 或关掉批处理 |
| CPU 模式 | 任何 x86_64 CPU 都能跑，但慢很多 |
| 磁盘 | 模型权重约 3 GB（随包提供） |
| 其他 | 首次运行会因为杀软扫描而**明显偏慢**，属正常现象 |

### 2.3 怎么配

打开 **设置 → 第三方工具（批量生成字幕 / 马赛克破解）**，把 `infer.exe` 的路径填进去。
**填 exe 的完整路径、或它所在的文件夹都可以**，留空则自动查找。

也可以直接改配置文件（见 `config.example.json`）：

```json
{
  "whisper_tool_path": "D:/Tools/faster-whisper",
  "whisper_device": "cuda",
  "whisper_sub_formats": "srt",
  "whisper_batching": true,
  "whisper_batch_size": 8
}
```

配好之后，回到「✍️ 批量生成字幕」页，点一下 **「探测能力」**：
本程序会读一次 `infer.exe --help`，**按你这个版本真正支持的参数**发命令。

> 为什么要探测：上游改过参数名。例如模型参数是 `--model_name_or_path`，
> 而它**根本没有** `--language` 这个选项 —— 写死参数名会在你机器上直接报
> "未识别参数"，而这类报错最难自查。探测之后，不支持的参数会被自动跳过，
> 并在日志里告诉你跳了哪些。

### 2.4 怎么用

1. 把视频拖进列表（**拖文件夹会自动展开**），或点「挑出库里缺字幕的视频」；
2. 选设备（GPU/CPU）、输出格式（SRT/VTT/TXT/LRC 可多选）、是否覆盖；
3. 点「开始生成」。可以暂停（当前文件跑完后挂起）、可以停止（连子进程一起结束）。

**输出位置**：默认写到**视频同目录**（Jellyfin 直接能读到）。也可以指定统一输出目录。

**「挑出库里缺字幕的视频」**：从媒体库读全部条目，挑出没有同名字幕的填进列表 ——
这是本程序相比单独用那个工具最省事的地方。

### 2.5 生成后的自动清理

勾选「生成后去重 / 拆长句」后，会按下面的规则处理（两个阈值可在设置里改）：

- **去重**：连续多条几乎一样的字幕（识别引擎在语气词/静音段上的常见毛病）只保留一条；
  只回看最近 8 条，所以片子前后出现同样的台词不会被误删；
- **拆长句**：单条超过 20 秒的字幕按句子切开并按时长比例分配时间轴；
  整条没有句末标点时就按字数切。

## 三、马赛克破解（Lada）

### 3.1 去哪儿下载

- **主仓库（下载页在这里）：https://codeberg.org/ladaapp/lada/releases**
- GitHub 只是镜像：https://github.com/ladaapp/lada
- 官方文档明确说明：**项目主页在 Codeberg**，GitHub 仅作同步镜像

下载 Windows 的 `.7z` 包（需要 [7-Zip](https://7-zip.org/) 解压），解压后会有：

```
lada.exe        ← 带界面的版本（你可以不用）
lada-cli.exe    ← 就是这个（本程序需要指向它）
_internal/      ← 依赖与模型权重，打包自带
```

> **模型权重是随包自带的**（`_internal/model_weights/`），不需要另外下载。
> 官方建议下载后核对 Release 公告里的 SHA256。

### 3.2 前置条件

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10/11 64 位 |
| GPU | **NVIDIA**（Turing 及更新：RTX 20 系 ~ 50 系）或 Intel Arc；显存 **4~6 GB** 起 |
| 内存 | 1080p 建议 6~8 GB；4K 需要明显更多 |
| 驱动 | 请更新到较新版本（官方反复强调） |
| 其他 | 首次启动会被杀软扫描，明显偏慢；CPU 也能跑但"慢到不实用" |

> 官方对效果的说明很坦率：有些场景接近真实，有些场景伪影比原来的马赛克还差。
> 这一点不是本程序能改变的 —— 它只是把 Lada 的批量操作变顺手。

### 3.3 怎么配

**设置 → 第三方工具**，填 `lada-cli.exe` 的路径（同样：填 exe 或它所在目录都行）。

然后回到「🔓 马赛克破解」页，点 **「读取能力」**。这一步会跑 5 次 `lada-cli.exe`
（约 10~30 秒，界面上有提示），把**你这台机器上真正可用**的：

- 编码预设（如 `hevc-nvidia-gpu-hq`、`h264-nvidia-gpu-fast` …）
- 检测模型（`v2` / `v4-fast` / `v4-accurate`）
- 修复模型（`basicvsrpp-v1.2` / `deepmosaics`）
- 可用设备（`cpu` / `cuda:0`）

全部填进下拉框。所以**下拉里出现的都是能用的**，不会选了之后才发现名字不对。

### 3.4 怎么用

1. 点「挑出库里判定为有码的视频」——用的是与「🎬 视频有码检测」**同一套判定**，
   已经破解过的会自动跳过；也可以自己拖文件进去；
2. 选预设/模型/片段长度等；
3. 点「开始破解」。进度会显示 `Processing video: NN%`（这是 Lada 唯一的进度来源）。

**输出**：默认写到**视频同目录**，文件名 `原文件名.restored.mp4`。

**和「🔄 破解视频替换」的联动**：那个页面认的就是 `xxx.restored.mp4`，
所以破解完直接去那一页替换回库中位置即可 —— 两页串成一条流水线，
页面右下角有直达按钮。

### 3.5 几个实用选项

| 选项 | 说明 |
| --- | --- |
| **片段长度**（`--max-clip-length`） | Lada 默认 180 帧。调大提升时序稳定性但更吃显存；调太小画面会闪烁 |
| **FP16** | 省显存，现代 GPU 上通常更快（默认开） |
| **跳过面部马赛克** | 避免面部区域的修复伪影，但可能降低对 NSFW 区域的识别率（默认关） |
| **产出后校验时长** | 用 ffprobe 对比输入/输出时长。**建议保持开启**：Lada 偶尔会以退出码 0 结束却没写出可用文件，只看退出码会把"静默失败"当成功 |
| **并发数** | 每个并发各占一份显存。显存不够就保持 1，否则会更慢甚至失败 |
| **显存门控** | 占用超过"高水位"时暂缓启动新任务，低于"低水位"时继续。适合边玩游戏边挂机 —— 但那两个阈值原本是按 12 GB 显卡调的，**请按自己的卡调整**。默认关闭 |

## 四、常见问题

**Q：为什么程序不直接带上这些工具？**
A：两个原因。一是体积与许可：`infer.exe` 38 MB + 模型 3 GB、Lada 解压后近 1 GB，
且它们各有各的许可证，不适合塞进本仓库。二是更新：上游更新比自己重新打包快得多，
你只要换掉那边的目录即可。

**Q：提示"未找到 infer.exe / lada-cli.exe"怎么办？**
A：功能页点「怎么获取？」，里面就是这份说明的要点；或者直接按上面第二、三节下载配置。

**Q：填了路径但还是说找不到？**
A：填的路径下必须真的有那个 exe（或它的一级子目录里有）。
设置页会显示**实际解析到的路径**，看那一行就知道程序到底找到了什么。

**Q：跑起来没反应 / 卡在 0%？**
A：字幕工具在加载模型（几 GB，首次很慢）；Lada 在准备模型（也会慢）。
两个工具的**原始输出都会实时打到日志面板**，看最后几行就知道卡在哪。
另外显存不足时会非常慢，先关掉批处理（字幕）/ 把并发降到 1（Lada）。

**Q：中途点了停止，会不会留下后台进程？**
A：不会。停止会结束**整个进程树**（这两个工具内部还会拉起 ffmpeg，
只杀主进程会留下占显存的孤儿）。这是实测验证过的行为。

**Q：我的显卡不是 NVIDIA，能用吗？**
A：字幕工具可以选 CPU 模式（慢）。Lada 官方只支持 NVIDIA / Intel Arc，
AMD 显卡目前没有可用路径。
