## 二、发现的问题（按严重度）

### P1-1 需求第二半完全缺失
`censor/releases` 不存在，`sources` 注册表空转。用户"确定有码后自动找无码版"的整条链路没有落点。

**已解决**：新增 `censor/releases/` 子系统（见 `docs/无码版本检索.md`），JavDB + JavBus 实测可用，Supjav 接入但需要 Cloudflare 旁路。

### P1-2 分析签名把**整份配置**算进去 → 改主题就全库重扫
`censor/service.py::_analysis_signature` 里 `"config": cfg` 取的是 `vars(self.cfg)`，
也就是说：改主题、改 AI 模型名、改 Lada 路径、改合并备份目录……**全部会让 700 部片的像素化缓存作废**，
下次打开全部重算（每部 30 秒，代价约 6 小时）。

**已解决**：改为只取 `censor_*` 前缀 + `uncensored_keywords`（`_analysis_config()`），
并加用例 `test_signature_ignores_unrelated_config_changes` 双向锁定：
改主题不失效、改阈值必须失效。

### P2-1 本机 device-id 被提交进仓库，且发布校验强依赖它
`.local/state/gh/device-id` 在 `git ls-files` 里，导致：

- `scripts/verify_release.py::source_digest` 把它当源码；
- 换一台机器（或 clone 后清掉 `.local/`）跑发布校验会直接 `ValueError: 源码文件缺失`；
- `.gitignore` 明明有 `.local/`，说明它是被 force-add 进去的。

**已解决**：`git rm --cached` 取消跟踪（本地文件保留），`.local/` 由 ignore 规则挡住；
`source_digest` 在新清单下仍为 64 位、相关用例通过。

### P2-2 仓库根目录有个 0 字节的 `zip` 文件
明显是误敲 `zip` 命令的产物，被一起提交了，还会进发布摘要。

**已解决**：删除。

### P2-3 死参数 `CensorOptions.skip_visual_when_series`
注释自己写着"仅保留调用兼容"，全仓库零引用。留着会让后来人以为"番号无码就跳过画面"这个行为存在。

**已解决**：删除。

### P3-1 `ui/pages/censorship.py` 职责过多
700 行，同时管：扫描调度、任务中心状态、复核推进、历史加载、延后选择、证据画廊、（现在还有）检索面板。
本次我把**检索的 UI 独立成 `ui/censor_release.py`**（线程 + 面板 + 复制磁链），页面只留接线。
后续建议：把"历史/延后/恢复"三块继续外移成 `ui/censor_history.py`。

### P3-2 文档冗余
`docs/有码检测.md`、`docs/像素化检测.md`、`docs/像素化检测验收.md`、`docs/像素化复核改进-2026-10-22.md`
四份内容重叠（同一套设计被写了三遍，数字还在漂移）。建议合并成一份"设计与实测"+ 一份"版本验收记录"。

### P3-3 无码厂牌名单有两份
`censor/numbering.py::UNCENSORED_PROVIDERS`（番号前缀）与 `censor/releases/javdb.py::UNCENSORED_MAKERS`（站点片商名）。
两者语义不同（一个判番号、一个判片商），**不该合并**，但建议在各自 docstring 里交叉引用一句，
否则以后有人会以为其中一份是冗余的。

## 五、建议的下一步（按性价比排序）

1. **用真实复核结果标定检测阈值**：`censor_label_history` 里已经积累了人工结论，
   拿它统计当前 `strong_score=32 / review=6` 的精确率与召回率，再谈"复核量降多少"有据可依。
2. **把"确有"接到替换流程**：现在能复制磁链；下一步可以在下载完成后自动调
   `utils/replacement.py` 更名落位并刷新标签，形成闭环。
3. **多线程检索**：目前串行是为站点礼貌；可以按 host 分池（同站串行、跨站并行），首轮时间能砍一半。
4. **Supjav 可用性**：如果愿意跑一个 FlareSolverr（MDCX 已配过 `127.0.0.1:8000`），
   破解版覆盖率会明显提升；配好后本子系统不用改代码。
5. **合并文档**（P3-2）。
