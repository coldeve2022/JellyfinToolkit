# 检测、版本检索与替换使用指南

适用：v3.20.0 源码版本。验收范围见 [本次验收](系统优化验收-2026-10-23.md)。

## 检查本地文件

在“像素化检查”添加文件、文件夹，或从当前媒体库范围导入。服务器条目必须有可访问的本地路径映射；导入后会显示不可访问或无映射的数量。扫描沿用排除词与视频扩展名设置。

默认先在后台核验文件版本、参数与缓存，再分析需要重查的视频。扫描中可以看表格、筛选和证据，修改检测设置与重新导入需要等待当前任务完成。停止会取消后续工作；未完成任务可以从更多菜单继续或重试，任务中心显示各阶段和错误。

画面分析报告局部网格结构。疑似、待复核和抽样低风险分别表示证据与复核流程，抽样低风险不能证明全片没有像素化。点击候选图可以放大；深入检查会增加取样。根据证据人工确认“有码”或“无码”，也可撤回当前确认，历史仍保留。换过文件后需要重新核验，旧标签不会自动继承。

检测设置可调整证据数量、并发上限和内存预算。实际并发还受 CPU 与分辨率约束。可选“媒体替换完成后自动检查新版本”；默认关闭，启用后只启动检查，不会自动代替人工标记。

## 查找其他版本

“找无码版”只接收仍然有效的人工有码确认，按作品番号聚合多个文件副本。无番号的记录会显示原因，不能通过相似标题猜测作品。人工确认后自动检索可在检索设置关闭；关闭后仍可手动检索。

常用操作为“检索所选”和“检索未查与过期”。更多菜单提供全部重查、失败重试、刷新和 CSV 导出。缓存期限、来源、Supjav 索引引擎、代理、旁路、超时、重试、详情上限、每作品请求预算和同时查询来源数由同一个设置部件管理，也可从全局设置修改。多个入口会更新未编辑的字段；尚未保存的本地编辑会保留。

默认同时查询 2 个来源，可调为 1–3 个。同站点仍执行最小间隔；各来源的代理路由状态独立，同一作品的请求预算由所有来源、重试和回退共用。停止会打断等待和阻止后续请求；已进行的网络读仍受配置超时约束。

| 显示 | 含义 |
|---|---|
| 确有 | 至少有一条匹配作品的候选带条目级强证据 |
| 疑似 | 只有标题等软线索，需要打开条目核对 |
| 未见 | 本次完成的启用来源没有提供无码条目；不代表互联网不存在 |
| 未查/未完成 | 没有可用结果，或来源被拦、失败、取消、部分未完成 |

来源内部某个引擎或详情失败也会标为不完整，不能冒充完整“未见”。失败/取消尝试单独保存，不覆盖之前成功缓存，恢复后可以重试。

候选页可以打开原站点核对。默认复制和导出的磁链要求其自身的番号与明确版本标记匹配；只有条目标题写“无码”、磁链版本未知时，不提供默认复制，仍可打开页面人工查看。普通有码候选不会成为默认替换下载项。工具本身不管理下载器或下载账号。

## 使用下载后的本地候选

选中作品，点击“导入已下载候选并审阅替换”。应用会跳到替换页的“按作品番号配对”模式；Lada 产物仍可使用原有 restored 名称配对模式。

先生成配对计划，再审阅每个源文件和目标。多个副本、多个候选争用同一目标、相同路径或容器不兼容时会阻止自动执行，需要调整输入。执行前的媒体校验、事务备份和任务中心恢复沿用原有机制；未经审阅不会自动替换。

文件替换成功会使旧检测记录失效，并根据检测设置安排复查。文件事务与 NFO/本地服务器数据库标签同步分别报告；同步失败不会抹掉已完成的替换记录。API 模式尚不主动发起服务器刷新，可在服务器端刷新媒体库。

已确认有码的当前文件也可交给 Lada。自动化工作台提供像素化检查和版本检索步骤，两者复用公共服务、当前范围、文件身份与缓存；不会把算法猜测自动变成人工确认。

## 调整工作区

两个核心页的更多菜单中可调整显示列、字体、表格行高和左右/上下分栏；列序、宽度、筛选、分隔条等保存在独立工作区偏好中。检测页还可调整画廊尺寸/列数、复核快捷键和标记后自动下一条。修改展示不会让分析缓存失效。

默认复核快捷键为 Alt+1、Alt+2、Alt+3。窗口较窄时可切上下分栏，并通过外层滚动区访问内容。清理证据入口只回收超过保留条件的未引用文件，当前报告引用的证据不会删除。

“恢复默认布局与偏好”会恢复最初的筛选、分栏比例、列与菜单勾选状态。真实外网站点连通性、长影片和 NAS 吞吐的验证范围见验收记录。
