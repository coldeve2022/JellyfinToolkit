# Jellyfin 复核联动与通用本地版本升级

用户已委托自行研究和实现细节。复用现有 PySide6、SQLite、媒体库数据源及可恢复文件事务；不操作真实媒体、不开发专用色情内容检索。

1. 收藏/观看快照绑定明确用户与数据源、范围和路径映射，本地 DB/API 共用已有读取链路；缺失证据保持未知，失败不把部分结果发布为完整收藏列表。
2. 复核表格增加喜欢、播放状态，喜欢/观看/结论/工作流/搜索共同筛选；支持喜欢优先、导入喜欢视频、只看喜欢且已确认像素化。异步刷新，旧用户结果不能落入新用户视图。
3. 短键限定当前工作区，不在输入框录入时触发人工确认；支持选中行复制、全选、搜索、复核及下一条，保持原自定义偏好。
4. 默认确认标签改为“有码 / 无码”，仅升级精确旧默认值；保留用户自定义，不自动批量改写历史外部元数据。
5. 选中视频可手动加入通用版本管理，逐行展示原版、新候选、配对/快照/继承状态。预览并保存状态后，用户审核同一计划才可执行。拒绝多候选/封装不匹配，沿用原路径和 NFO，保留回滚与身份校验。
6. 替换前保存条目可编辑元数据、NFO/附属文件和可访问用户状态；服务器刷新排队不等于继承完成，另行验证 ID、元数据及用户状态。API 无法安全恢复的差异明确待处理，不伪造播放会话或在线改服务器数据库。
7. 独立模块先 RED→GREEN，集成后完整回归、使用说明与本地 Windows 构建。已有真实记录只做只读核验，所有写测试均隔离。
