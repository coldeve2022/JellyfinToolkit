# 复核按钮与批量补图修复计划

沿用用户对当前目录直接检修、必要功能可直接实施的授权。范围是通用本地视频取样、证据图片和复核交互；不改专用检索生产逻辑。不访问真实库、不重写用户确认标签。

## 根因与设计

- 标签同步由页面拥有的TaskManager任务执行，通用任务锁误把两个人工标记按钮锁住。给同步任务和复核控件增加显式协作标记，只在该任务期间豁免人工复核按钮；批量确认仍保留任务互斥。
- 深检只提高分析数量，概览仍补足到六张、合并又受普通证据数量/时间间隔限制。显式深检单独设证据预算，保留结构候选并增加全时段概览；后续轮次调整分层取样相位，避免重复相同采样时刻。
- 新增选中项批量补图、当前筛选缺图批量补图和选中项深入检查。补图只取参考画面，保留原检测状态/错误与人工确认；单次任务由现有有界并发worker调度，不需逐条启动。
- 补图复用精确取样、原子PNG写入及文件身份核验，不计作重新分析，不覆盖扫描待办；成功/部分成功/失败记录独立操作回执。保留旧图、避免重复画面，证据总量有上限。

## 实施与验收

1. 先加失败回归：同步任务按钮灰闪、多选深检丢选区、深检证据仍六张、补图接口及状态保留。
2. 修复任务协作豁免，验证只有同步任务保留按钮，其他互斥任务仍锁定。
3. 共用相位取样及额外证据预算，检查正常采样默认签名兼容，深检保留更多参考图片且不改变结构判定门槛。
4. 实现补图服务及现有worker批量入口，覆盖成功、部分失败、取消、文件变更、已有确认。
5. 整合表格多选/右键/缺图筛选入口、进度反馈和操作记录；不打乱复核选择与顺序。
6. 合成视频、定向和完整回归，更新日志并独立版本出包，保留旧程序与资料库。
