# 通用视频流程第二轮审计与修复

日期：2026-10-23。源码版本：3.20.1。基线：`58f512d`。工作目录沿用用户指定项目；未修改真实媒体或个人配置，未连接真实媒体服务器。

## 范围与方法

对项目 Python/pyw 文件做完整静态语法清单、非平凡函数体精确重复检查、Ruff 和隔离回归；人工逐段复核本轮取样、分析、缓存、人工确认、分页、任务与 UI 相关路径。清单含 271 个文件、63,686 行，不含虚拟环境、构建产物、用户数据与第三方源码。清单本身不等于每条分支均被执行，也不能证明软件不存在其他缺陷。

现有 3.20.0 已包含上一轮修复与打包结果。本轮针对新复现缺陷改动源码；`dist` 中原有程序不会随源码自动更新。没有开发、联网验证或增强专用成人影片版本检索渠道。

## 十二项要求对应结果

| 用户要求 | 本轮处理及证据 |
|---|---|
| 1. 功能无法使用 | 修复坏缓存/坏偏好阻止正常流程、陈旧缩略图误报成功、隐藏行导航、坏历史页卡住；合成集成回归验证。 |
| 2. 重复或不一致逻辑 | 单帧缩略图复用共同进程生命周期；两个缓存入口共用恢复及确认融合；数据库各读入口共用字段与解码契约。 |
| 3. 软件 bug | 下表列出已复现并修复的类别；新增测试先失败再修复，另有一次独立只读审查。 |
| 4. 不直观流程 | “下一条”只访问筛选范围；筛掉当前项就清空操作目标；空文件、旧文件版本、历史坏行分别处理。 |
| 5. 缺失能力 | 补充真实帧时间戳、可取消的旧缩略图入口、坏行分页游标、重复计算统计与坏偏好独立恢复。没有凭空添加无验证依据的内容分类功能。 |
| 6. UI 自定义与布局 | 保留已有列、字体、行高、分栏、图宽/列数和快捷键自定义；修复损坏值恢复、身份列不可达、窄图库、小屏放大窗和缩放重绘。 |
| 7. 联动协同 | 复核选择、人工确认、撤回、后台缓存与持久队列共同核验当前文件版本；原有跨页事件和通用媒体事务用全量测试回归。未扩展专用检索联动。 |
| 8. 扫描效率 | 重复像素复用 CV，静态片段不重复计算；复核队列一次数据库读取；任务连接及时关闭。性能见下表，未声称整体扫描倍速。 |
| 9. 历史保存与复用 | 坏行不堵住正常记录；确认后复用完整自动证据；失败/取消重查不覆盖成功证据；撤回不套用旧文件版本；改超时不使成功缓存失效。 |
| 10. 关键帧准确性与速度 | 继续使用跨时段精确解码，避免仅取 I 帧漏掉长 GOP 内变化。通过同次 FFmpeg 的整数 PTS/time_base 标注实际画面位置，未新增每帧 FFprobe；总览分布到首、中、尾。 |
| 11. 提前清洗、减少确认 | 空文件在解码前失败；文件发现沿用排除词、临时产物/附件排除与规范路径去重；已有有效人工确认及分析复用；相同像素少计算，但不充当多份独立证据。来源名称（包括 FC2）不能证明画面内容，未据此自动确认或跳过核验。 |
| 12. 通用功能范围 | 本轮所有新增媒体测试均用普通合成像素/视频；没有访问媒体站点或新增内容定位渠道。 |

## 已复现修复

| 位置 | 根因与修复 |
|---|---|
| `censor/sampling.py` | 请求位置被当成帧时间；改读实际 PTS，归一化播放起点。覆盖 CFR、VFR、长 GOP、非零起点与精度；保留必要 showinfo 记录，避免大 SEI 挤出错误日志尾部。 |
| 同上 | 缩略图失败/EOF 时旧文件仍使函数返回成功；改为临时文件成功后原子替换，失败保留旧图且返回失败。统一取消/超时与非法参数报错。 |
| `censor/mosaic_cv.py` | 同样像素每次重算，且总览偏向最初六帧、候选限额可被追加总览突破；改为维度+通道+像素摘要缓存紧凑分析结果，均匀总览并遵守上限。 |
| `censor/store.py` | 坏枚举/数值导致整条扫描失败，非有限候选值及坏框导致渲染问题；共同解码入口按坏行/坏候选隔离，不主动删除历史。 |
| 同上 | 复核列表逐视频打开连接；改为一次快照流式读取，达到页长就停止。各读入口共用列顺序常量。 |
| 同上、复核页 | 跳过坏行后按有效条数推进分页，可能重复或永远停住；返回实际读取行对应的下一偏移与是否有后页。 |
| `censor/service.py` | 人工确认会优先旧数据库结果而丢失刚完成的显式分析；仅完整的新分析优先，失败/取消/部分完成时保留有效成功分析，没有成功分析则只存独立人工确认。 |
| 同上 | 新增确认改变签名后重扫会丢失视觉证据；允许同一文件、同一分析设置的完整自动缓存重新融合当前人工确认。人工跳过视觉的结果不能冒充完整视觉分析。 |
| 同上 | 撤回在文件替换后返回旧像素证据；改为只返回匹配当前版本的记录。无匹配分析时 UI 显示需重查。 |
| 同上 | 超时设置无关成功结论却使缓存失效；从分析签名排除。空输入在解析检测器和工具前报错。 |
| `censor/jobs.py` | SQLite `with connection` 只提交/回滚，不关闭连接；改用显式关闭的上下文管理器，异常路径也回滚并关闭。 |
| `ui/pages/censorship.py` | 下一条沿用过时筛选文案、可能选择不可见行；按当前实际筛选选择，过滤当前项时清除展示与操作目标。 |
| `ui/workspace_preferences.py` | 一处损坏布局中断所有恢复，shortcut 类型异常，身份列可能隐藏后无法恢复；分项恢复并规范化配置，身份列保持可达。 |
| `ui/censor_gallery.py` | 固定最小尺寸、小窗裁切、resize 不重绘、缺图/坏图残留旧画面；保留原始图片按窗口重绘，窄图库允许缩图，缺图立即清空。 |

## 保留的兼容与限制

- 精确重复清单中的四个命令行 UTF-8 自配置函数保留，以兼容脚本独立执行和直接路径导入；工具搜索的两个同形入口依赖各自工具名称，但已共用 `utils/tool_search.py`，没有因此新增一套搜索器。AST 精确相同不等于应盲目合并。
- 视觉检测器版本由 3 升到 4，旧自动视觉结果在首次使用新算法时可能需要重算；已有人工记录不删除，仍核验当前文件版本。并发、内存、超时及展示变化不应单独要求重算成功结果。
- 存储沿用最新自动分析与人工版本/事件历史，没有新增“永久保留每次扫描所有解码帧”的大容量档案。
- 抽样不足、完全重复画面和低风险都不能证明全片不存在像素化。本轮没有推断哪种内容区域“重要”，也没有按来源前缀免检。
- 未重新打包 EXE，未提交、发布或修改个人媒体。使用现有旧 EXE 不会自动获得这些源码修复。
