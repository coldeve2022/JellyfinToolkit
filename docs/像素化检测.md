# 通用视频像素化检测

界面与跨功能操作请看 [检测与版本替换使用指南](检测与版本替换使用指南.md)；本文保留算法和接口说明。

检测局部块状网格结构，不识别画面语义或身体部位，不联网检索视频版本。

## 结果如何理解

- **疑似像素化**：抽样中至少两个相隔指定时间的候选达到强结构阈值，仍需复核，不是校准概率。
- **待确认**：单个强候选、弱结构、仅有元数据或覆盖不足。
- **抽样低风险（未确证）**：抽样至少24帧、完成目标的80%、至少4种不同画面，且最高结构分低于候选阈值。默认不进入人工待办，可单独筛选检查；状态仍为 UNKNOWN，未声称全片不存在。
- **名称线索·延后**：旧历史中名称有明确无码/破解线索且无视觉候选的项目；人工选择后实际检出的视觉候选仍进入复核。
- **人工确认未见**：对当前文件版本的人工记录。文件发生变化后，不自动继承。
- 失败、取消、部分完成独立于检测结论展示，并列出实际已分析/已抽样帧数。

条纹、棋盘、像素画、全局低清和视频压缩都可能产生结构相似性。程序检查的是网格证据，不能从相同像素结构证明其制作目的。即使多帧出现，也不保证一定属于人工遮挡。

旧版关键帧/fps方式可能重复源画面。新版改用分段精确 seek，在各时间段内确定性偏移，避免固定周期重复；候选继续按时间间隔和分析像素摘要去重，重复像素不累计独立强证据。这也意味着完全静止的像素化画面会保守地留待确认。

## 分层与扩展

`models` 保存证据、状态、候选；`identity` 计算文件版本；`sampling` 负责 FFmpeg；`mosaic_cv` 生成视觉证据；`fusion` 生成结论；`store` 管 SQLite；`service` 负责执行、签名、缓存与取消；`evaluation` 提供无敏感内容的合成基准。UI 只调用服务。

新增检测器继承 `BaseDetector`，声明 `name`、`version` 和 `capabilities`。能力 `visual` 遵守画面开关；能力 `ffmpeg` 会获得工具路径。注册方式沿用 `detectors.add`。算法或默认行为变更时必须提升检测器 `version`，避免复用旧缓存。显式空名单代表不运行检测器，未知插件会报告错误。

## 配置

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `censor_windows` | `[80,160,240]` | 多尺度滑窗；空列表沿用单尺度 `censor_window` |
| `censor_frame_samples` | 60 | 目标抽帧数量；正常短流可少于目标 |
| `censor_sample_width/height` | 960/540 | 分析分辨率，缩放可能改变块结构 |
| `censor_sampling_timeout` | 900 秒 | 单次抽帧时间上限 |
| `censor_candidate_gap_seconds` | 10 秒 | 候选与独立强证据的最小时间间隔 |
| `censor_strong_score` | 32 | 强网格阈值，不是百分比 |
| `censor_review_score` | 6 | 候选保留阈值 |
| `censor_candidates` | 18 | 保存的证据图上限，可在“更多 → 检查设置”调节；全部滚动显示 |
| `censor_min_phase_consistency` | 0.7 | 同方向行间边界相位一致比例，抑制不对齐重复纹理 |

块大小、行采样、覆盖率、能量比等高级参数也可从配置覆盖。独立使用 `MosaicParams(window=...)` 默认保持单尺度兼容；应用配置默认启用多尺度。

分段稀疏抽样仍会遗漏短暂区域；候选时间是精确 seek 的请求时间，并非读取出的源帧 PTS，定位存在帧间隔误差。缩略图直接由实际分析的像素生成，避免二次 seek 取到别的帧。程序没有声称逐帧检查。提高抽样数量能增加时间覆盖，但有速度和内存成本。

## 缓存和人工记录

自动缓存核对文件大小、纳秒修改时间及分段 SHA256。摘要读取开头、中间、末尾各最多 64 KiB，能发现普通替换，不能发现所有未采样位置的同大小同时间编辑。分析签名包含配置、策略、插件版本/能力、检测选项、服务器标签及生效 NFO 摘要。

仅完整成功结果可自动复用；参数/输入改变会重新计算。扫描开始和结束都检查文件身份，变化时不缓存。`use_cache=False` 不读写自动结果。

人工记录保存在版本历史表；旧路径级记录迁移保留，但不作为当前文件的确认依据。清自动结果不会清人工历史。SQLite 会添加兼容列，不需要删库重建。

## 验证与评估

```powershell
python -m pytest tests -q
ruff check .
python scripts/version_manage.py check
python tools/dev/evaluate_pixelation.py --output evaluation-multiscale.json
python tools/dev/evaluate_pixelation.py --single-scale --output evaluation-single.json
python tools/dev/evaluate_pixelation.py --ffmpeg <ffmpeg完整路径> --ffprobe <ffprobe完整路径> --output evaluation-encoded.json
```

合成基准包含自然式纹理、渐变、文本、条纹、黑边、棋盘、全局低清、局部块平均，并分开开发与验证 seed。棋盘和全局低清标为歧义，不混入二分类准确率。结果记录分数、耗时、参数、算法版本和分组统计。它只检验机制，不代表实际媒体库精确率/召回率；后者需要独立标注的普通视频验证集。

## 连续复核

标注后自动进入下一待复核项。Alt+1 确认存在、Alt+2 确认未见、Alt+3 暂时跳过。面板滚动显示全部保留图，候选有红框和局部裁剪，点击可放大；零分概览单独标注为覆盖取样，不算命中。旧缓存没有裁剪图，需要重新分析补充。

“此视频 → 深入检查”忽略自动缓存，以配置抽样数的3倍检查（最多600帧），并保留已有人工结论。分析完成自动刷新当前面板。算法版本升为3，重新添加视频时旧自动缓存失效；不会自动重扫整库。
