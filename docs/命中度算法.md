# 命中度（内容匹配）算法详解

本文档说明「智能整理工具」如何计算每部未看作品与你的喜好的匹配程度（命中度），以及由此得出的分类（喜欢/删除/待复核）。代码实现位于 `utils/scoring.py`、`utils/library.py`、`utils/tag_norm.py`。

---

## 1. 总览：一条作品从库到分类的流水线

```
Jellyfin 数据库
   ↓ 采集(collect_library)
作品条目(Item)  ← 番号/名称/演员/厂商/类型/标签/大小/年份/无码/CD分卷…
   ↓ 特征提取(item_features)
特征向量 { 演员、厂商、番号前缀、题材、标签、无码标志 : 基础权重 }
   ↓ TF-IDF 区分度加权
加权特征
   ↓ 与你的「喜欢/不喜欢画像」比对
命中度 coverage ∈ [0,1]（增强模式下再叠加锚点/共现）
   ↓ 决策分层
已看/收藏(keep) ｜ 可能喜欢(like) ｜ 建议删除(delete) ｜ 待复核(review)
```

---

## 2. 特征是什么（一部作品如何被描述）

从 Jellyfin 的 `Genres / Tags / Studios / Actors` 等字段提取，拆分成"特征键"，每类有**基础权重**：

| 特征类别 | 来源 | 基础权重 |
|---|---|---|
| 演员 actor | 演员表 | 3.0 |
| 厂商 studio | 片商字段 | 2.0 |
| 番号前缀 prefix | 番号破折号前的字母段（如 FC2-、MIRD- 的 FC2/MIRD） | 2.0 |
| 题材 genre | Genres 字段 | 2.0 |
| 标签 tag | Tags 字段 | 1.0 |
| 无码 uncensored | 无码关键词判定 | 0.3 |
| 分桶 bucket / 年份 year | —（无判别力，权重 0，不参与） | 0 |

**关键预处理**：
- **垃圾清理**：剔除 `发行:… / 片商:… / 系列:…` 前缀（刮削器塞进字段的杂质）、`H264/1080P` 等技术词、`720P/H264` 等。
- **同义合并**（`utils/tag_norm.py`）：`中出し→中出`、`顔射→颜射`、`ハメ撮り→はめ撮り`、`個人撮影→个人摄影`…，让同一概念的写法统一成一个特征，避免同一口味被拆成两条稀释权重。
- 所有特征进入评分前都先做**归一化去重**。

---

## 3. 你的「喜好画像」是怎么来的

只用**你看过的作品**当训练信号（收藏=2、看完=1、有进度=0.6、播放过=0.3 的行为权重累加），**绝不拿"没看过"当依据**：

- 每部已看作品的每个特征，按 行为权重×基础权重 累加进"喜欢账本"。
- 累计强度超过阈值 `LIKED_THRESHOLD` 的特征 → 进入 **liked 集合**（你确实喜欢这个特征）。
- **不喜欢集合** 来自：你在打标页手动标记的删除作品 + AI 参与分类提炼的 disliked 特征。
- 每一版新评分都会根据当前打标**重排**——你标得越多画像越准。

---

## 4. 命中度（coverage）核心公式

对一部未看作品，取其加权特征集合，与 liked / disliked 比对：

```
命中度 = ( 命中的喜欢特征权重 − 0.5 × 命中的不喜欢特征权重 ) ÷ 该作品全部特征权重

全部特征权重  = Σ 每个特征 (基础权重 × TF-IDF区分度)
```

- **TF-IDF 区分度**（`idf_weights`）：
  `idf(t) = log((1+N)/(1+df_t)) + 1`
  - N = 全库作品数，df_t = 含该特征的作品数。
  - 效果：**人人都有的通用标签（中出、巨乳…）自动降权**，**稀有偏好（冷门演员/冷门题材）升权**——避免通用词稀释匹配。
- 命中度在 0~100% 之间；**没有任何特征**（演员/类型全缺）→ 视为"无信息"，不评分、强制走待复核。

**通俗理解**：命中度 ≈ "这部片的内容里，有多少比例是你画像里验证过的喜欢点（扣掉你验证过的不喜欢点）"。

---

## 5. 增强匹配（设置页可开关，默认开）

开启后，在命中度之上再叠加两个信号（`enhance`）：

```
最终命中度 = clamp( coverage + 0.25 × 相似锚点 + 0.10 × 题材共现 )
```

| 信号 | 计算 | 作用 |
|---|---|---|
| 相似锚点 | 你的所有喜欢作品的特征求一个"质心向量"，本片特征向量与它算**余弦相似度** | 用整体口味（多特征组合）判断，而不是只看单个标签命中；理由会显示"⟶ 最像你喜欢的 xx" |
| 题材共现 | 你喜欢的作品里，哪些特征**经常一起出现**（如 素人+中出+无码）；本片若命中这些组合 | 组合口味打分，比单特征更接近真实偏好结构 |
| AI 语义注入 | AI 参与分类提炼的语义特征（liked/disliked）并入画像 | 让模型补充标签之外的语义关联 |

**关闭增强** = 只按第 4 节的 coverage 计算，便于对比优化前后效果（设置页「增强匹配」勾选框）。

---

## 6. 最终分数与决策分层

对每部未看作品，最终综合分：

```
final = 1.0×命中度 + 0.1×画质分 − 1.0×去重惩罚
```

- 画质分：基于大小/分辨率的弱信号（权重低）。
- 去重惩罚：重复组里"差版本"扣分，趋向删除。

**决策规则（按顺序）**：

| 情形 | 判定 |
|---|---|
| 你已看过/收藏/手动标记保留 | **保留 keep**（行为真值最高优先，不看命中度） |
| 无任何元数据 | **待复核**（无法预测） |
| CD 分卷（同一作品多集） | **待复核**（需整体判断，不能自动删） |
| 命中度 ≥ 55% | **可能喜欢** |
| 命中度 ≤ 25% | **建议删除** |
| 25% < 命中度 < 55% | **待复核**（边界，需你判断） |

> 阈值 55%/25% 可在设置页调整。命中度是"相对你画像"的，**数值本身不绝对**——同样是 60%，画像越准确越可信。

## 7. 一个具体例子

假设你喜欢过的作品里有：`希咲那奈(演员) MOODYZ(厂商) 中出(题材) 无码`，画像把这些点亮。

新片 **MIRD-270** 特征：`演员: 希咲那奈、某某`、`厂商: MOODYZ`、`题材: 中出`、`标签: 素人`。

1. 全部特征权重（含 idf）之和 = 分母。
2. 分子 = 命中"演员希咲那奈"的权重 + 命中"厂商MOODYZ"的权重 + 命中"题材中出"的权重（若"中出"是全库高频词，idf 会让它权重偏低，这是故意的）。
3. 命中度 = 分子 ÷ 分母 ≈ 70%+（多特征命中且含高权重演员）。
4. 增强：与你的质心余弦相似度高 → 再加分；理由显示"⟶ 最像你喜欢的 XX-123"。
5. 70% ≥ 55% → **可能喜欢**，进入快速打标页"② 可能喜欢"列表。

若新片只有 `演员: 完全没见过的演员、题材: 从未看过的冷门题材` → 命中度接近 0% → **建议删除**；理由会附上该片自身的元数据（演员/类型/大小），方便你人工核对。

---

## 8. 已知边界（诚实说明）

- 命中度依赖**元数据质量**：刮削器没抓到的片子特征稀疏，命中度天然偏低，容易误判"建议删除"——所以无元数据/低信息的一律进"待复核"而不是直接删。
- 命中度是**内容相似度**，不是"这部片好不好看"；新导演、新系列无历史画像可依，靠"相似锚点"兜底。
- 你的画像只反映"已验证的偏好"，漏掉你还没尝试但会喜欢的类型——用「🎲 随机换一批」探索。
